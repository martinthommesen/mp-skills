## Evidence levels

- **Static inspection:** parsed metadata, resource inventory, or comparison of source bytes. It establishes a file property, not runtime behavior.
- **Instruction application:** a fresh evaluator reads a disposable fixture and reports the next permitted actions. Actual loaded paths establish file loading; proposed actions are interpretation. No interview, question UI interaction, lesson, install, chat lifecycle, or workflow execution is implied.
- **Executed check:** a local command runs and its exit/output is recorded. Packaging tests establish package behavior; the frozen hook fixture establishes hook behavior for synthetic command text.
- **Host execution:** the requested native workflow runs through the actual host. No Task 2 probe claims this level. Native picker discovery and end-to-end interview execution remain pending an isolated runtime check.

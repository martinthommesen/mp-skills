## Evidence levels

- **Static inspection:** parsed metadata, resource inventory, or comparison of source bytes. It establishes a file property, not runtime behavior.
- **Instruction application:** a fresh evaluator reads a disposable fixture and reports the next permitted actions. Actual loaded paths establish file loading; proposed actions are interpretation. No interview, question UI interaction, lesson, install, chat lifecycle, or workflow execution is implied.
- **Executed check:** a local command runs and its exit/output is recorded. Packaging tests establish package behavior; the frozen hook fixture establishes hook behavior for synthetic command text.
- **Host execution:** the requested native workflow runs through the actual host. No Task 2 probe claims this level. Native picker discovery and end-to-end interview execution remain pending an isolated runtime check.

Disposable fixtures live under `/private/tmp/mp-skills-task2-probes/`. They are copied skill directories, not a normal profile installation. Neither `HOME` nor `CODEX_HOME` was repurposed. A catalog case cannot borrow another case's prerequisite.

The earlier staged observations in `.superpowers/sdd/2026-10-08-codex-native-skills/baseline-probes.md` found literal-tool failures and underspecification. The fresh baseline evaluator instead adapted correctly in all three composition cases. These findings are recorded separately: the text was brittle, but the fresh baseline agent did not fail. The changes make its successful routes explicit.

## Limitations and extension

The probes do not prove native skill-picker rendering, actual host auto-discovery, actual optional-question return behavior, or an end-to-end interview. The staged question schema matches the exposed optional-only contract used for the evaluation, but the evaluator did not call that tool. Native runtime checks should use an isolated configuration or disposable environment, never the normal profile.

Later tasks append scenario IDs for their own setup, worktree, review, lifecycle, and frozen compatibility checks. Preserve the evidence level and baseline observation columns rather than converting a predicted action into a claim of host execution.
